本后台通过 GitHub 令牌直接读写网站仓库，提交后自动部署。
请粘贴 Fine-grained PAT（仅需授予 anliways/anliways-site 仓库的 Contents 读写权限）。令牌只保存在本浏览器，不会提交到任何服务器。

令牌创建：github.com/settings/personal-access-tokens/new → Repository access 选 "Only select repositories" → anliways-site → Permissions 里 Contents 选 "Read and write"。
